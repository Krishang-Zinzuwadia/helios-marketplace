# Helios Marketplace

Helios Marketplace is an early, one-page catalog of 15 small-model specialists
for software work. Instead of starting with model brands, it starts with the
job: front end, back end, DevOps, security, testing, data, documentation, and
more.

## What works today

- Search and filter all 15 roles
- Sort the catalog by its default order, name, or area
- See what each specialist needs, gives back, handles, and won’t do
- Use the site with a keyboard or on a phone

## Development

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

## What comes later

The catalog data is hardcoded for now. Model downloads, benchmarks, the Helios
runtime connection, compatibility checks, and the install flow are not built
yet.
